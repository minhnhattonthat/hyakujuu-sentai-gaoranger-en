# Text engine

## Encoding (verified: decoded known on-screen lines, cell sheet checked by eye)
- No Shift-JIS anywhere (sjis_scan over EXE, PRGs and every unpacked leaf). Relative search fails because the code
  space has gaps: **glyph code = 0x00A0 + row*0x20 + col** of the font sheet, 21 columns used per 32-code row.
- Glyphs are **big-endian u16** `00A0..01F4` (high byte 00 or 01). Control bytes: `81` = 1-byte space (between
  choices, in "ぬきさし しないで"), `82` = newline, `85 xx` = 1-arg attribute (colour? guess; debug menu / title
  strings), `FF` = end. After `FF`, 2-4 zero bytes pad to the next string (role unknown, keep).
- Table: `tbl/jp.tbl`, generated by `tools/make_tbl.py` from the row strings there (edit those, not the .tbl).
  Rows 4 and 8 put handakuten before dakuten (はぱば, ハパバ); ゐゑヰヱ are absent; 1D2 = 々; only kanji:
  方向上下左右 and 下 (in 下さい).
- Font: 4bpp TIM, VRAM (960,0) 64x256 (=256x256 px), CLUT at (304,240). Cell 12 px wide, rows 16 px apart:
  u = (code & 31) * 12, v = (code >> 5) * 16 (row 0 at v=80). Copies: CARDMS.PAC/1, Y_TITLE.PAC/12_5, O_START.PAC/8
  and others (same 0x8540-byte TIM). Cell sheet: `python -X utf8 tools/fontsheet.py work/pac/CARDMS.PAC/1.bin out.png`.
- Proof: DS_ST01.PAC/13_12 string 3 = 「ガオのせんしたちよ…」, matches the screen at tour frame ~6000 and RAM
  0x801cdf2a (`work/qa/seq`, state `work/qa/tour1/s004500.sstate` + ~1300 frames).

## String tables (verified by tools/textscan.py: every offset decodes to FF)
- u16 LE a (0), u16 LE count, count x u16 LE offsets from file start, then strings. Many entries share one offset
  (an unused default string), so unique strings << entries. `O_TITLE.PAC/2` ends with an offset = file size (empty).
- `python -X utf8 tools/textscan.py [--show]` lists 22 tables, 307 strings (many duplicates across files):
  - DS_ST01..07.PAC `13_12`: story intermission dialogue (3-4 lines each, voiced, typewriter box).
  - DE_ST01..05, Y_EDSAVE, Y_SAVE `14_13_1`; Y_LOAD `13_13_1`: save/load messages.
  - CARDMS.PAC/0, Y_TITLE/21: memory-card messages. Y_TITLE/20, /22, Y_OPTION `13_12`: title/option strings.
  - O_TITLE.PAC/1: leftover **debug menu** (テスト, ステージセレクト, dev names OTA NODA YAMA MIYA, RANGER ROBO
    DEMO, hex digits): use for phase 2. O_TITLE.PAC/2: system messages (memory card, "ザ・あべし" high score).
- `tools/runscan.py --skip-tables` (grammar sweep, any offset) finds nothing else but noise (しし.. in pixel data).
- Not found yet: in-battle text, if any (likely all graphics). The box speaker name is a graphic (graphics.md).

## Extraction (phase 4, `tools/extract.py`, tests/test_extract.py)
- `script/<name>.json`, one per unique table (15; 280 strings). Identical tables share one JSON: `save` is in
  DE_ST01-05 + Y_EDSAVE + Y_SAVE, `card` in CARDMS/0 + Y_TITLE/21; insertion must write every file in `files`.
- Per string: `id` = `<name>-<original offset>`, `slots` (entry indexes pointing at it), `jp`, `en`, `pad` (zeros
  after FF), `notes`. `{n}` = newline (82), `{col:XX}` = 85 xx, ASCII space = 81, `　` = glyph 00A0.
- Strings start 2-aligned; padding after FF is 1-4 zeros. A glyph's high byte can be 00, so string starts come
  from the offsets, not from "first non-zero byte". `extract.build` keeps 2-alignment when lengths change.
- O_TITLE/2 header count is 195; one entry = table size (empty end slot, `end_slots`). O_TITLE/1 holds one
  unreferenced string "BANDAI" at 0x62a (`slots: []`, kept).
- Roundtrip: `extract.build(json) == original leaf` for all 22 files; coverage: textscan finds tables exactly in
  those leaves, and the grammar sweep of every other leaf, the EXE and PRGs finds only pixel noise.
- Likely non-text / debug-only (decide in the marker build): `debug` (O_TITLE/1 debug menu), `title_debug`
  (Y_TITLE/22, incl. a 21-glyph ruler `123456789012345678901`), hex digit and dev-name strings in `title`.
