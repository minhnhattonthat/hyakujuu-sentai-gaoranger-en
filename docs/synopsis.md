# Synopsis - Hyakujuu Sentai GaoRanger (PS1, Bandai/Natsume, 2001)

An action game on the 2001 Super Sentai show. The five GaoRangers (Gao Red, Yellow, Blue, Black, White) fight the
Orgs (oni-like monsters, Tetomu's "wicked ogres"), first on foot in action stages, then as giant robots (GaoKing and
its combinations) in robo battles. Dialogue is small: before each chapter Tetomu, the Gao shrine maiden, briefs the
team in one story box (script/ds01-07, 3-4 lines each); she also voices the save, load and option messages.
Everything else (plates, banners, game over, credits) is graphics text.
